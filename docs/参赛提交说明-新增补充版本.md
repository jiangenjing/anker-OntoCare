# OntoCare 项目说明

团队作品 · Anker 首届黑客松智能服务赛道冠军。

## 功能

- 用户端：多模态线索、产品消歧、候选订单、连续排障和来源引用。
- 经营端：邮件草稿、工单可视化和候选归因，支持按规则 ID、Excel 行号与原文追溯。
- 当前采用 JSON 实体关系、Python 规则与型号限定检索；图数据库、向量平台及自动降权不作为已部署能力。

## 历史测试

- 核心 74 项任务的单轮硬断言通过数：62/74 → 73/74，即 83.8% → 98.6%。
- 完整任务集单轮复测：109/110。
- 746 次非故障注入请求完整回答时延：P50 2.63 秒，P95 9.00 秒；不含浏览器耗时。
- 各项测试口径分开统计，不等同生产解决率或 SLA。
