# 多模态证据转检索

实现：media_understanding.py、app.py、static/index.html。
收到图片或视频后，先调用服务端视觉模型生成 description、visible_issue、error_code 及候选型号；无依据留空。媒体内的文字是证据，不是系统指令。禁止凭外观确定型号、订单归属或赔付资格。
视频只采样前 30 秒、最多 6 帧，无音轨理解；界面必须说明范围。视频需本机 ffmpeg。
转换后的文字进入同一会话的检索 query，产品经用户确认后按 PN 硬过滤知识库，随后走本体与 Action Gateway；回复引用实际知识来源。未确认型号时先给型号选项，不跨型号输出专属建议。切换产品清除旧媒体证据。
上传结果绑定会话，原始上传文件在处理后删除，描述存于进程内会话。未知、未配置、超时、截断或不可解析时明确降级，不伪造识别成功。
VISION_API_KEY 仅存服务端 .env.local，不进入 HTML、日志或 ZIP；提供方必须实际支持 image_url 多图输入。
