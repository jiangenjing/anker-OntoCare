# 引用校验

对应模块：app.py / source_view

引用必须指向实际使用的公开来源。型号不符、来源不存在或消费者不可见时拒绝引用。澄清回复标注本轮信息和服务规则，不能伪造知识来源。来源改变后旧固定答复失效。

这是当前应用的职责规范，不代表独立运行的多 Agent 进程。约束由对应 Python 模块实现，并通过测试验证。

邮件来源单独引用原表 C 列；客户陈述不能当作核验后的订单事实。草稿引用和商家核对证据保持一致，本地链接不是客户可访问的外部支持页面。

待实现验收要求：ID存在不代表支持每个结论。下一步将金额、SKU、订单状态、日期等断言绑定具体源字段；用“正确ID但错误结论”作为负例。当前运行时尚未完成逐句蕴含校验，不得宣称已有此能力。

评测沉淀来源：long-tail-eval-001～006 为项目核查策略，不是安克官方政策；引用链接必须可解析。固定 FAQ 仍附原始 Q&A 引用。订单来源页也遵守地址隐藏；禁止以“引用原文”为由绕过隐私边界。
