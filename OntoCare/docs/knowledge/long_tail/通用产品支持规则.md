# 通用产品问题：先排查，后核验订单

- 用户已说明产品类别和故障时，先检索对应类别的可信通用资料。不因缺少订单号或完整 PN 阻断有依据的通用排查。
- 一般使用、充电与基础排查无需订单；个案物流、保修、退款等资格判断仍需真实记录与核验。
- 优先既有同型号 FAQ；型号不在赛题产品清单时，允许使用明确适用的类别资料。禁止把充电器新增为虚构订单或 SKU。
- 设备类别要隔离：有线、无线、充电宝、吸奶器及扫地机不能互套。无法确认时先问设备类别。
- 安全风险优先停止使用并建议人工核查，不继续通电测试。
- 回复之后展示相关通用问题/结果反馈按钮，并绑定官方知识节点。不展示无关演示订单。
- 双语 JSON 是检索补充，不是模型训练；原始政策承诺不直接进入生成上下文。
