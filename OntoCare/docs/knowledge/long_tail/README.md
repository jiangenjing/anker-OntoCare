# 长尾库接入说明

运行时读取 `长尾场景策略库.md`、`长尾问题_检索策略.json` 和 `评测修复策略库.md`；`用户提供原文_未核验_不参与检索.md` 仅用于审阅溯源，不传给 LLM。

启动时由 `long_tail_knowledge.py` 解析 52 个条目；每轮按明确词组匹配最多 3 条。此分类是场景候选标记，不是有真实频率统计的“小众概率模型”。命中现有 FAQ / 精确错误码 / 连续排障 / 安全阻断时保留原路径优先级。

客服与商家邮件共用现有 chat 处理链。命中策略后带来源 ID 进入 grounded 模型输入，并仍受既有 allowed / forbidden 限制；无模型或调用失败只显示核查策略，不冒充已执行操作。不把个性化长尾回答写入公共答案缓存。

修改 Markdown 后重启服务生效。每个条目固定 ID，请保留字段名、分隔符与标题格式；扩展时同步更新回归测试。
