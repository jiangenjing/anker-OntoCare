# 订单卡片

输入真实订单号或载入有订单的工单后，在聊天中显示订单确认卡。全部商品明细保留，不用工单文字推测包裹对应商品。首层展示描述、SKU、数量、源表金额和状态；展开后展示原始序号、购买日期、质保结束日期、承运商、物流单号、发货日期与源表地址。每个商品有原始行引用。

- 包裹图标为通用示意，不是产品照片；资料未提供产品图片，不编造照片。
- 空字段显示未提供；金额保留源表数值，不从数值猜币种。
- 订单确认只确认咨询对象，不能确认购买人身份或批准售后。
- 多商品卡提供“查询这件商品”；换一笔会聚焦订单输入框。
- 同一订单不会每轮重复弹卡；换订单重新展示。历史卡保留，刷新可恢复；演示工具同步最新订单字段。
- 不把用户粘贴的错位表格重新覆盖源表；例如T29C2001作为Anker002的商品明细保留。

验证：106项Python测试通过，包括全部订单逐字段对照、Anker002两条明细、确认不授权、切换订单、查无、物流号不误作订单号、历史恢复与脚本可访问。

浏览器验证：输入Anker006后显示主机与配件两条卡片，展开可查看原始日期、地址和物流字段；仅输入订单号直接引导选商品，不再重复要求提供型号。
