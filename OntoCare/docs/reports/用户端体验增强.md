# 用户端体验增强

## Plan → Action
1. U01：源表订单卡 + 产品图文选卡，点击进入同一会话；明确是演示候选，不能推定用户身份。
2. U02：每轮重新检索本体关系，最多三条最近订单明细优先、按当前场景推荐，补齐六条可点选问题；日期缺失排后。
3. U03：沿用真实处理进度流，不添加虚假的400ms延迟，不暴露内部思维链，不保证远程模型2.5秒完成。
4. U04：本轮引用的公开Q&A含图片时显示图示按钮与弹窗，可关闭、有源文链接；没有图示的条目不伪造部件位置。知识图示为源表中的远程URL，需要网络，失败时显示原文入口。
5. U05：每条回复下方有有帮助、没解决和人工入口；没解决支持自由反馈和三条快捷选项。反馈保存在当前服务进程的会话中，重启不保留；人工入口继续遵守超过8轮的转接条件，不声称已经接通真人。
6. U06：正文编号和下方引用可展开、收起；显示真实原文预览及完整来源链接。

## 图片与数据
已保存5个产品系列官方图：T2080、T8D04、T2351、T2353、T2280。图片在static/product-images/，manifest.json记录原官方页面和原图片URL。仅用于系列辨识，颜色及套装以SKU源数据为准；配件与其他无核验图片的产品显示暂无已核验图片。官方产品页与源表不一致时，图片不用于推断订单金额、规格、保修或物流。

排序使用源表购买日期，不把产品发布日期或工单日期当购买日期；不使用建议文件里的示例字段替换真实源表。多件订单保留原始行引用。用户选定订单后不再推送其他产品选择卡。
