# ontocare本体队提交版

## 启动
需要 Python 3.10+，首次安装依赖需要联网。Mac 双击「启动.command」或在本目录运行 `bash run.sh`。
打开 http://127.0.0.1:5088/ 。若旧版占用端口，先关闭旧服务，或使用 `PORT=5089 bash run.sh`。
复制 `.env.example` 为 `.env.local`，在 COMPETITION_API_KEY 填入有效比赛密钥后重启；也可在本机「模型与多模态」页面配置。提交包不包含真实密钥、虚拟环境或临时上传文件。

## 手机 / 电脑
同一套页面按屏宽自动布局：手机单列、桌面多列，导航和宽表格各自在内部横向滚动。
预览入口：http://127.0.0.1:5088/device-preview.html 。手机模拟 402×874 CSS 像素，电脑模拟 1440×900；选择页面可并排查看。
已在浏览器双视口检查客服、商家、看板、归因决策、评测结果、业务基线、评测原理、多模态八个页面。未进行 iPhone 真机 Safari 的软键盘和录音权限测试。
同 Wi-Fi 手机访问电脑的局域网 IP:5088 可查看页面。模型配置和模型测试 API 当前保留本机访问限制；手机远程调用需要后续部署带鉴权的 HTTPS 服务，不能仅靠 CSS 适配解除。远程 HTTP 页面麦克风也可能被浏览器限制。

## 评测与证据
历史核心任务线上硬断言 62/74（83.78%）→ 修复后单轮 73/74（98.65%），提升 14.86 个百分点。保留 benchmark 与 reports 下的原始证据；不代表多轮稳定性或语义准确率。
多模态识别文字是待核验材料，确认型号和适用知识之后才能形成售后决策。调试记录展示真实模型、操作、耗时、错误码，不输出密钥及原始文件。语音转写需要人工纠错。

## 结构
- app.py / run.sh：Flask 应用与启动入口
- static/：响应式前端及双端预览
- ontocare_multimodal/：比赛模型与多模态适配
- agents/、knowledge/、data/：业务规则、知识和源数据快照
- benchmark/、reports/、evaluation/：历史评测与证据
- tests/：回归测试
- tools/：页面生成脚本，响应式样式同步到导出报告
