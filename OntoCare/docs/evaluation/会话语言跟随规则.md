# 会话语言跟随规则

自动聊天模式跟随用户最近一次明确使用的语言。中文提问回复中文，英文提问回复英文；用户改用另一种语言时从当前轮开始切换。单独的订单号、型号、SKU、数字、错误码、标点沿用上一轮语言；新会话默认中文。邮件等显式指定目标语言的调用保留该能力。

服务端把 response_language 存入会话，并用于回复 Prompt、规则兜底、流式进度及推荐问题。前端读取服务端实际语言，同步推荐问题、快捷回答、选择卡消息、输入提示和语言切换器。刷新页面从会话快照恢复语言。服务进程重启仍遵循原项目的内存会话生命周期。

知识库推荐问题提供中文提问模板和英文原始标题，保留对应型号、错误码与引用 ID，不调用额外翻译 API。原始资料、产品名称、订单号和引用原文不改写。

英文生成正文出现中文、中文生成正文完全没有中文时，按语言不匹配处理并回退，避免显式错误语言结果展示。此项为基础检查，不宣称达到完整的语言学语种判定。中文资料兜底不再把长篇英文原文直接粘贴到回复，原文仍能从引用打开。

排障切换语言时保留检查记录；只有明确逐项对齐的双语步骤可以共享步骤位置。中英文缓存清单结构不同时，不自动将一个版本的第 N 步映射到另一版本的第 N 步，交给有引用的模型说明或人工核查。

修改位置：customer_signals.py、app.py、followup_questions.py、conversation_workflow.py、grounded_response.py、user_experience.py、docs/prompts/agents/responder/Agent.md、static/index.html、static/user_experience.js。

验证：143 项单元与回归测试通过，新增 9 项语言测试；两项旧测试的英文输入后中文预期已按新规则改为英文，保留其原有话题切换、证据及意图断言。浏览器实测覆盖中文→英文→型号续问→中文，以及推荐选项、快捷回答、引用和刷新恢复。
