## 如何复验
1. 启动./run.sh。
2. `.venv/bin/python -m unittest discover -s tests -q`。
3. `.venv/bin/python evaluation/run_suite.py`：规则与固定参考日。
4. `.venv/bin/python evaluation/run_suite.py --live`：真实服务与已配置模型，消耗API额度，不发邮件。
