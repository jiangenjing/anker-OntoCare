# 业务与字段说明

## 经营目标
识别重复咨询与排障负担，支持客户风险优先处理和知识补齐。当前63条工单是源表快照，不能表示真实整体售后发生率。

|资料|关键字段|关联与解释|
|---|---|---|
|客诉工单信息.xlsx|原文行号、产品线、产品名、SKU、订单号、客户首封邮件内容、咨询场景、附件|源表行号保留表头偏移；一行一工单，原文是证据|
|订单信息|订单号、SKU、购买日期、质保结束日期、物流状态|订单可有多个商品；质保要匹配同SKU|
|经销商信息|渠道、地区、经销商信息|用于渠道核实，不凭名单认定责任|
|Robovacs / Breast Pump Q&A|PN、Title、Content、Status、Consumer Visible|按型号和公开状态匹配；标题未命中不代表全文无答案|
|SOP与规则|适用条件、允许动作、禁止动作、rule_id|业务方须确认版本与适用地区；分析窗口不是实际质保政策|

派生字段：row=Excel行号；pn=可验证产品编号；codes=展示错误码；raw_codes=原始内部码；complaint_date=原文明确日期；order_rows=同订单明细行；emotion=词组规则输出。

## 数据不足
部分日期、SKU、订单关联和客户信息缺失；保持未提供。暂无销量、完整时间序列、实际处理时长、重开率和动作执行回执，不能编造经营降幅或“最近集中爆发”。

## 部署与密钥
实时问答沿用服务端 LLM_BASE_URL / LLM_MODEL / COMPETITION_API_KEY（或 LLM_API_KEY）。密钥不放浏览器、Markdown或静态HTML。推荐问题默认四版预设演示，实际API问答独立标识；逐字呈现不等于模型 token 流。
