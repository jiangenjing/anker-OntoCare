问题严重程度分布

P0：未核验信息披露 / 越权等潜在高风险；P1：答案、状态或故障处理不符要求；P2：体验指标未达标。统计失败断言，不是独立缺陷数量。
固定订单探针只控制故障变量，不代表该订单属于每个 Persona。人工超时在传输边界等待 5.05 秒后抛出；真实模型正常请求另行计时。

故障矩阵 · 4 类故障 × 8 类用户

每格为首轮注入结果：回答可用、实际命中注入点、显式 degraded_reason 均满足才通过；任一不满足均保留为失败。

真实答案返回时间

排除人工故障与离线运行。测的是 Python 应用处理 + 实际模型 API 往返，未包含浏览器渲染和外部 HTTP 接入层。当前答案一次性返回，所以答案 TTFT ≈ 完整回复时延。

等义扰动与会话隔离

同义词、语序、噪声分别使用 3 个事实一致的输入，比较订单、SKU、产品、质保和渠道终态；并行测试使用 4 个独立会话。
主观体验分由同一模型、独立裁判提示词给出，属于估计；未做人类标注一致性验证。界面可点击性另有浏览器检查，不能用模型评分替代。

衔接、恢复与话题切换

会话恢复验证同一进程内重新读取上下文；尚未验证服务重启后恢复。转人工只验证本地待审核队列，不声称已接通客服或发出邮件。

当前仍需人工 / 生产验证的部分

  • 同模型裁判偏差及多语言人工复核。
  • 真实渠道身份、购买凭证和订单归属核验。
  • 生产物流接口、交易执行器及审批闭环。
  • 长周期 FCR、重开率、真实服务转人工率。
  • 浏览器实际首字和移动端、断网重连、服务重启恢复。
